# 快速收藏文件夹选择

## 目标

为侧边栏顶部“收藏当前页”增加服务器书签文件夹选择能力，让用户可以在收藏前指定保存位置。

## 实施步骤

1. 从当前服务器书签树生成可选文件夹列表，保留根目录选项。
2. 在快速收藏卡片中增加“保存到”选择器，默认根目录并保持现有紧凑布局。
3. 收藏当前页时将选择的文件夹 ID 作为 `parentId` 提交到服务器。
4. 补充客户端契约回归测试，验证文件夹 ID 不会丢失。
5. 更新开发记录和版本记录，执行类型检查、测试与 Chrome/Firefox 构建。

## 验收标准

- 用户可在收藏前选择根目录或任意已有文件夹。
- 收藏成功后书签出现在所选文件夹中，未选择时行为与之前一致。
- 选择器在窄侧边栏中不撑破卡片，连接未建立或无当前网页时仍不可操作。
