# 书签侧边栏开发记录

## 2026-09-17：修复侧边栏白屏

- 为 WXT 开发服务器启用 CORS，允许 Chrome Side Panel 从扩展来源加载 localhost 开发模块。
- 修复国际化初始化错误使用 `WeakMap.size` 的无效优化条件。
- 收紧文件夹选择器与虚拟列表的类型边界，恢复扩展严格 TypeScript 检查。

## 2026-09-16：修复扩展图标显示

- 浏览器扩展清单的 `icons` 与 `action.default_icon` 统一使用 `logo.png`。
- 保留 WebP 作为页面品牌 Logo 资源，但不再将其用于扩展清单图标，兼容 Chromium 和 Firefox 的扩展图标加载。
- 完成 Chrome MV3 构建并增加清单图标回归检查。

## 2026-09-13：服务器书签库自动同步

- 侧边栏在页面可见期间每 10 秒静默刷新服务器书签库，重新获得焦点或恢复可见时立即刷新。
- 自动刷新保留现有列表，避免 Loading 状态导致内容闪烁，并使用请求锁避免并发重复请求。
- 在统计区域显示最近同步时间，手动刷新按钮和服务器唯一数据源提示保持不变。

## 2026-09-12：修复回到顶部按钮

- 固定侧边栏工作区的可滚动高度，避免滚动落到页面根节点。
- 按钮点击时兼容工作区、文档根节点和窗口滚动位置，并使用即时回顶确保浏览器实现差异下仍然生效。

## 2026-09-12：文件夹显示书签总数

- 文件夹行增加书签总数徽章，统计当前文件夹及嵌套子文件夹中的全部书签。
- 侧边栏文件夹背景保持统一宽度，仅通过左侧内容缩进表达层级。

## 2026-09-12：快速收藏支持选择文件夹

- 顶部“收藏当前页”增加服务器文件夹选择器，可保存到根目录或任意已有文件夹。
- 收藏请求沿用服务器书签库 `parentId` 字段，默认根目录行为保持不变。

## 2026-09-12：缓存网站图标

- 使用浏览器 Cache Storage 按网站域名保存已下载的 favicon，后续打开侧边栏时直接复用本地缓存。
- 同一域名的书签共享缓存和并发加载任务，避免列表中重复请求相同 Logo。

## 2026-09-12：修复顶部 Logo 尺寸

- 将顶部品牌 Logo 放入 28×28 固定容器，避免原始图片尺寸撑高标题栏。

## 2026-09-12：修复网站图标尺寸

- 为栅格 favicon 同时增加 HTML 尺寸属性和 CSS 尺寸约束，保证异常比例网站图标仍固定显示为 16×16。
- 增加图标槽尺寸回归检查并完成测试、类型检查与 Chrome 构建。

## 2026-09-12：服务器书签库模式

- 将侧边栏的数据源替换为服务器书签库，收藏当前页直接保存到项目数据库。
- 移除浏览器 `bookmarks` 权限及原生书签 API 调用，保留标签页打开能力。
- 完成服务器书签库客户端契约、类型检查、Chrome 与 Firefox 构建验证。
