# 管理后台整体 UI 视觉升级计划

## 目标

在不改变业务逻辑、接口和页面信息结构的前提下，统一管理后台的视觉语言与交互反馈，使概览、数据管理、安全管理、系统设置和帮助页面具备一致的层级、密度和可读性。

## 范围

- 重构全局颜色、阴影、圆角、间距和焦点态设计令牌。
- 升级桌面侧边栏、导航选中态、退出入口和主内容背景。
- 统一面板、统计卡片、按钮、输入框、表格与提示状态。
- 提升概览页、分类管理工作区和功能页的视觉层级。
- 保持现有桌面视口锁定、分类页双栏和移动端自然滚动行为。
- 不修改 API、数据模型、书签移动逻辑和权限边界。

## 执行步骤

1. 盘点现有全局样式与关键页面结构，确定覆盖层边界。
2. 建立新的设计令牌和应用壳视觉，统一侧边栏与主内容区。
3. 升级通用面板、控件、表格、状态提示和功能页组件。
4. 单独校准概览页与分类管理页面，避免破坏固定布局和内部滚动。
5. 检查桌面与移动端响应式规则，修复文字溢出和交互状态。
6. 执行类型检查、测试和生产构建，记录开发与版本更新并提交本地仓库。

## 验收标准

- 所有后台页面共享一致的背景、面板、控件和导航视觉。
- 侧边栏层级清晰，导航项和状态反馈稳定，无文字或图标溢出。
- 分类管理页面左右模块保持可见，页面不发生滚动穿透。
- 桌面端内容密度适合后台操作，移动端保持可滚动和可操作。
- 类型检查、现有测试和生产构建全部通过。

## 执行结果

- 已完成全局设计令牌、应用壳、侧边栏、内容标题栏和账户区升级。
- 已统一面板、按钮、表单、统计卡片、列表、状态提示和功能页视觉。
- 已校准概览页、分类管理工作区与移动端布局。
- 类型检查、13 项测试和生产构建均通过。
