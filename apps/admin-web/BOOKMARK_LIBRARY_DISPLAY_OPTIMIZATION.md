# 服务器书签库展示模块优化

## 目标

优化管理后台“我的服务器书签库”列表，让书签名称、网站域名、文件夹和操作入口层级更清晰，并改善大量书签下的浏览效率。

## 实施步骤

1. 将书签列表行改为更明确的图标、内容和操作分区。
2. 通过 API 统一解析、缓存并代理网站 favicon，前端按网站 origin 复用结果，固定图标尺寸，避免布局抖动。
3. 优化标题、网址、域名和文件夹标签的截断与响应式布局。
4. 保留现有搜索、刷新、删除和回收站行为，不改变 API 数据契约。
5. 补充前端回归测试，执行类型检查、测试、生产构建和差异检查。
6. 更新开发记录并创建本地 Git 提交。
7. API 端限制远程请求协议、目标地址、响应大小和图片类型，避免 favicon 代理被滥用为 SSRF。

## 验收标准

- 每条书签可优先显示对应网站图标；图标加载失败时仍保持固定占位。
- 首次解析后图标写入服务器数据目录的 favicon-cache，后续访问不再依赖站点实时响应。
- 标题和网址在窄窗口下不会撑破列表，文件夹标签和删除按钮仍可用。
- 搜索结果数量、刷新、删除和恢复功能保持不变。
- admin-web 类型检查、测试和构建全部通过。
