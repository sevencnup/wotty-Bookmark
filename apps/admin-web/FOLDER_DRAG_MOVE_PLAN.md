# 组织树文件夹拖动移动开发文档

## 目标

- 允许在右侧组织树中拖动文件夹，并将整棵文件夹子树移动到其他文件夹。
- 允许将文件夹拖到“全部书签”，使其成为顶级文件夹。
- 禁止移动到自身或自己的任意子孙文件夹，避免循环结构。
- 复用现有 ETag、文件锁、原子写回和索引流程，保证不会覆盖 Floccus 的并发同步结果。

## 后端步骤

1. 新增文件夹移动请求和 `/api/v1/bookmarks/folders/move` 路由。
2. 验证源节点存在且类型为文件夹；目标为空时代表根目录，否则目标必须为文件夹。
3. 遍历文件夹父子关系检查目标是否位于源文件夹子树内。
4. 在事务中更新源文件夹的 `parent_id` 与目标位置，子孙节点保持原父子关系并整体跟随。
5. 提交事务后调用现有书签文件重写流程，返回新 ETag 和版本号。
6. 增加循环、目标不存在和合法移动的测试。

## 前端步骤

1. 扩展拖动状态，区分书签拖动和文件夹拖动。
2. 文件夹卡片支持拖动，目标文件夹根据合法性显示接收或禁止状态。
3. “全部书签”根卡片支持接收文件夹，作为移动到顶级的入口。
4. 禁止自身和子孙目标，并显示明确提示。
5. 移动成功后刷新树，保留相关展开状态，并由 SVG 连接层自动重绘。

## 验收标准

- 文件夹拖到另一文件夹后，其全部子文件夹和书签保持原结构并整体迁移。
- 文件夹拖到“全部书签”后成为顶级文件夹。
- 自身和子孙节点不能成为目标，后端即使收到非法请求也必须拒绝。
- 书签拖入文件夹功能保持可用。
- 展开、收起和 SVG 曲线在移动后保持正确。
- 前后端测试、类型检查和生产构建全部通过。
