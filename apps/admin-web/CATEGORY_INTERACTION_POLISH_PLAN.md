# 分类管理交互与视觉收敛开发文档

## 目标

- 移除左侧文件夹分组的侧边颜色标注，继续使用整行底色区分文件夹与书签。
- 保留复选框多选，并增加按住书签行拖过多行的连续多选能力。
- 将右侧组织树的直角分支连接改为圆角弯曲连接。
- 移除搜索输入框内部的蓝色焦点边框，保留搜索容器自身的焦点反馈。

## 实施步骤

1. 调整文件夹分组和搜索框的最终覆盖样式，避免旧样式或全局焦点样式反向覆盖。
2. 在书签列表实现基于 Pointer Events 的连续选择：按下首行确定选择或取消模式，拖过其他行时沿用同一模式。
3. 排除拖拽手柄和打开链接，保持书签归类拖拽与外链打开行为不变。
4. 使用带圆角的 CSS 边框连接替换组织树节点的直角横线，保持递归树布局和缩放逻辑不变。
   - 父文件夹右侧必须主动引出连接线，并接入子级竖向主干。
   - 主干与父级出线、子级入线需要轻微重叠，避免缩放后出现断口。
5. 补充交互提示、开发记录和版本记录。
6. 执行类型检查、单元测试、生产构建和差异检查，再创建本地 Git 提交。

## 验收标准

- 文件夹分组四周边框一致，不出现左侧彩色竖条。
- 鼠标按住任意书签行并滑过其他行，可连续选择；从已选行开始则连续取消。
- 复选框键盘操作、拖动手柄和打开链接不受连续选择影响。
- 组织树父子分支以圆角曲线接入节点，不再表现为生硬直角。
- 每个有子级的文件夹都从卡片右侧引出分支线，连接到所属子级主干。
- 搜索框聚焦时输入框内部不出现蓝色矩形边框。
- `lint`、`test`、`build` 全部通过。
