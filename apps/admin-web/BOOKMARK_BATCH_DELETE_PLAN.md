# 分类管理批量删除开发文档

## 目标

- 勾选一个或多个书签后，在批量操作栏显示“删除”按钮。
- 删除操作需要二次确认，并将书签移入管理后台回收站。
- 一次请求完成批量删除，避免逐条删除引起 ETag 变化和重复写回同步文件。
- 删除后重写 WebDAV XBEL，使 Floccus 可在后续双向同步中识别远端删除。

## 后端步骤

1. 新增批量移入回收站请求与路由。
2. 使用登录鉴权、明文 XBEL 状态检查、ETag 校验和文件锁保护。
3. 在同一事务中校验全部书签、写入回收站记录并删除索引节点。
4. 事务提交后只重写一次 XBEL，返回删除数量、新 ETag 和版本号。
5. 增加空选择、重复选择和 API 请求契约测试。

## 前端步骤

1. 批量操作栏增加危险层级的删除按钮。
2. 点击后显示包含书签数量和同步影响的确认对话框。
3. 成功后清空选择、刷新书签树并提示已移入回收站。
4. 失败时刷新最新 ETag，并保留明确错误提示。

## 验收标准

- 选择书签后可一次删除多个书签。
- 删除的书签出现在回收站，并从重写后的 XBEL 中消失。
- ETag 过期时不覆盖 Floccus 的并发更新。
- 原有选择、拖拽移动、文件夹组织树和 SVG 连线保持可用。
- 前后端测试、类型检查和生产构建全部通过。
