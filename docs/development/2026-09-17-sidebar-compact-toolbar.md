# 侧边栏紧凑工具区开发文档

## 背景

侧边栏首屏同时显示服务器说明、搜索、快速收藏、书签统计和新建操作。窄侧栏下这些辅助内容会占据大量垂直空间，影响书签列表的可见范围。

## 目标

在应用标题栏右上角提供一个可切换的紧凑模式按钮。紧凑模式收起辅助工具区，保留品牌、连接状态、书签库标题和列表；再次点击可恢复完整工具区。用户的选择需要在扩展本地保存。

## 实施步骤

1. 新增布局偏好读写模块，使用扩展本地存储保存紧凑模式状态。
2. 在标题栏右侧添加带说明和无障碍状态的紧凑模式切换按钮。
3. 为辅助工具区增加包裹容器，在紧凑模式中通过样式收起；不卸载内部控件，避免丢失正在输入的搜索关键词或收藏目标文件夹。
4. 为收起/展开和键盘焦点状态增加样式，并在紧凑模式减少工作区顶部留白。
5. 添加偏好模块测试，执行类型检查、单元测试和 Chrome MV3 构建。
6. 更新版本与开发记录并创建本地 Git 提交。

## 验收标准

- 标题栏右上角有清晰的紧凑模式切换按钮。
- 紧凑模式不再占用服务器说明、搜索、快速收藏和统计操作的垂直空间。
- 展开后原有工具区和已有输入状态保持可用。
- 切换状态在重新打开侧边栏后保持。
- 类型检查、单元测试和 Chrome MV3 构建通过。
