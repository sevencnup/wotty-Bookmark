# 侧边栏书签插件域名展示与可变高度虚拟滚动优化方案

## 1. 问题诊断

在引入固定高度 `BOOKMARK_ROW_HEIGHT = 38px` 虚拟滚动后，由于书签项包含标题和网址域名两行内容（自然高度约 52px），而 `.bookmark-row` 被强制约束为 `height: 38px`，导致第二行的域名文字被垂直方向截断和压缩成扁平细线。

## 2. 改造目标

1. **精确区分节点高度**：
   - 文件夹行（Folder Row）：高度固定为 `38px`（极简单行）。
   - 书签项（Bookmark Row）：高度固定为 `52px`（完整展示标题与来源域名）。
2. **升级虚拟滚动窗口算法**：
   - 增强 `virtual-list.ts`，提供 `getVariableVirtualWindow` 支持按节点类型计算前缀和位置与二分查找，确保混合高度列表的视口计算和 padding 偏移 100% 精确。
3. **优化书签行 CSS 样式**：
   - 书签行 `.bookmark-item-row` 与文件夹行 `.bookmark-folder-row` 显式设置对应的高度与内部 flex/margin 间距，彻底消除域名文字压缩。
4. **验证与回归测试**：
   - 补全可变高度虚拟滚动的单元测试用例，确保空列表、全文件夹、全书签、混合列表及边界滚动下的正确性。
