# 侧边栏书签域名视觉质感重构方案

## 1. 现状痛点分析
1. **Windows 下等宽字体视觉分裂**：`ui-monospace` 在 Windows 环境下回退为类似 Courier New 的细长机械感点阵字，字符间距过大，显得松散杂乱。
2. **缺乏严格垂直对齐基准线**：域名左侧缩进没有严格与上方书签标题的文字起始端对齐。
3. **字重与色彩层级失衡**：500 字重加粗在小字号下有锯齿感，缺乏现代精致感。

## 2. 改造方案
1. **切换为现代无衬线西文字体族**：
   - 统一采用 `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", sans-serif`。
   - 字母紧凑、圆润、抗锯齿平滑，与现代浏览器原生体验完全一致。
2. **严格对齐标题文字基准线**：
   - 书签标题在 `bookmark-row-main` 中的有效起始位置与 `bookmark-url` 的左侧 padding 精确对齐。
3. **优化色彩与字阶层级**：
   - 字号设为 `11.5px`，字重设为 `400`（正文常态），颜色采用清爽柔和的石板灰 `#64748b`。
4. **验证与回归**：
   - 保证单元测试全部通过，执行扩展打包构建，更新版本记录并本地提交。
