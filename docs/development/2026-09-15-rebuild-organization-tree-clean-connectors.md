# 彻底修复分类管理组织架构树布局与连线重构方案

## 1. 现象与根本原因剖析

### 1.1 截体现象
1. **树形分支线条悬空、断裂、错位**：
   - 顶级文件夹左侧出现一条无限向上向下贯穿的垂直线，且脱离文件夹卡片；
   - 子文件夹左侧出现孤立且高低不一的细竖线，没有与父文件夹或子文件夹卡片连接；
   - 整体看起来像断断续续的错乱竖线。

### 1.2 根本原因
1. **类名层叠与作用域混乱**：
   - 2270~2301 行定义了旧版 `.organization-root-rail`、`.organization-children` 的绝对定位规则（使用了居中 50% 向上向下的老样式）。
   - 2676~2820 行定义了新版 `.category-management-page .organization-root-rail`。两套样式属性（`padding`、`margin`、`before/after`）互相穿插覆盖。
2. **DOM 嵌套结构的几何锚点缺陷**：
   - 顶级文件夹容器 `.organization-root-rail` 和子文件夹容器 `.organization-children` 中的连线伪元素没有严格绑定在各自的父级坐标系中。
   - 子文件夹的 `::before` 连线参考点基于外部容器而不是当前节点的行高，导致多节点连续排列时出现一截一截的错位竖线。

## 2. 解决方案：现代标准分层树状总线（Deterministic Tree Bus Architecture）

### 2.1 彻底清理全部历史混乱 CSS
- 完全清理 2274~2301 行的旧版组织树样式，统一收敛至 `.category-management-page` 命名空间下唯一维护。

### 2.2 构建标准的纯 CSS 水平/垂直树形连接体系
- **根节点（Root Card）**：
  - 放置在左侧，保持 `min-height: 64px`，向右发射一条干净的水平引线连接到主总线。
- **顶级文件夹总线（Main Vertical Bus）**：
  - 由 `.organization-root-rail` 构建垂直导轨，精准贯穿第一个顶级文件夹到最后一个顶级文件夹的垂直中点。
  - 每个顶级文件夹节点从主总线获得一条平滑水平连线连接至卡片左侧。
- **子文件夹总线（Child Branch Bus）**：
  - 当父文件夹展开时，右侧展示子文件夹列表。
  - 父文件夹卡片右侧发射水平线，连接到子分支的垂直总线。
  - 子分支垂直总线精准对齐并连接各个子文件夹。

## 3. 实施步骤
1. 重构并精简 `apps/admin-web/src/styles.css` 中所有与 `organization-` 相关的样式，消除任何重复规则。
2. 精确计算每条连线的像素高度与偏移量（卡片行高、分支间距、拐角线）。
3. 运行全量测试与构建，验证本地渲染。
