# 管理后台全局本地化修正

## 背景

首版语言偏好只覆盖了管理后台外壳和偏好页，业务页面仍保留中文，不符合“全局切换”的预期。

## 目标

建立统一的管理后台本地化层，使简体中文与 English 的切换覆盖所有已挂载管理页面的文本、按钮、表单提示、弹窗、辅助标签和危险操作确认内容。语言切换必须即时生效并在刷新后保持。

## 实施步骤

1. 为语言模块增加全局本地化 Provider 和页面文本替换能力。
2. 建立完整的中英文界面词典，覆盖后台可达页面及其动态状态文案。
3. 处理属性文本、动态数量、操作提示和危险确认信息；跳过用户创建的书签与文件夹内容。
4. 将全局本地化层接入应用根部，并让危险操作确认使用当前语言。
5. 添加翻译与持久化回归测试，运行前端测试和生产构建，记录版本并创建本地提交。

## 验收标准

- 选择 English 后，任一可达管理页面不再显示项目内置中文界面文案。
- 简体中文切换保持原有文案和布局。
- 书签标题、文件夹名称、网址、账户标识等用户数据保持原样。
- 刷新、重新登录和危险操作确认都使用当前语言。
