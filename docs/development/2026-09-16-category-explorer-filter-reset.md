# 分类管理目录切换筛选重置修复

## 问题

分类管理右侧的资源管理器文件夹视图会在进入、返回或通过面包屑切换目录时保留“过滤当前层级文件夹”的输入内容。若新目录的子文件夹名称不匹配旧关键词，页面会错误显示为没有文件夹。

同时，目录卡片的 `bookmarkCount` 由服务端递归统计当前目录及全部子目录中的书签，却被前端标记为“直属书签”。

## 目标与验收

1. 每次在资源管理器中切换目录（进入、返回上级、点击面包屑或回到根目录）时，清空右侧文件夹筛选。
2. 切换后展示目标层级所有直接子文件夹，不受上一个目录的关键词影响。
3. 目录统计文案准确描述递归统计，使用“包含 N 个书签”。
4. 为目录跳转状态建立纯函数测试，覆盖进入目录、回到根目录及筛选清空。
5. 通过管理后台单元测试、类型检查和生产构建。

## 实施步骤

1. 提取目录切换状态的纯函数，统一返回目标目录、左侧选择状态及已清空的右侧筛选。
2. 将进入、返回上级和面包屑导航统一接入该函数。
3. 修正统计文案，并添加回归测试。
4. 运行验证，更新版本记录并创建本地 Git 提交。
