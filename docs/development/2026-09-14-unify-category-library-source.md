# 统一分类管理与服务器书签库数据源

## 目标

消除“分类管理”和“我的书签库”读取不同数据库表导致的文件夹、书签和删除状态不一致。分类管理改为直接展示并操作服务器书签库，确保两页始终反映同一棵文件夹树。

## 实施步骤

1. 将分类管理页的数据加载从 Floccus 同步索引切换到服务器书签库。
2. 将分类管理页的书签移动、文件夹移动和删除操作映射到服务器书签库 API。
3. 移除分类管理对 Floccus 加密状态、同步基线和同步回收站的依赖，保留 Floccus 兼容页面与存量数据。
4. 更新页面说明，明确分类管理与我的书签库共享同一份服务器数据。
5. 补充回归测试、运行前端构建与后端测试，并创建本地提交。

## 验收标准

- 两页展示相同的书签和文件夹数量、层级与删除状态。
- 分类管理中的移动和删除立即反映到我的书签库及侧边栏。
- 已移入服务器书签库回收站的文件夹不再出现在分类管理。
- Floccus 兼容能力不被删除或修改。
