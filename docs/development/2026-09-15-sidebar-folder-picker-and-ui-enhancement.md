# 侧边栏文件夹选择器搜索化与 UI 体验升级方案

## 1. 需求背景与目标
用户反馈在侧边栏插件使用中存在以下体验痛点：
1. **新增/编辑/移动弹窗中的文件夹选择 UI**：原生 `<select>` 样式简陋、在 Windows 下展开效果粗糙。
2. **新增/编辑/移动弹窗中的文件夹搜索**：当书签库包含数十上百个分类文件夹时，纯下拉列表查找极为困难，需支持就地搜索过滤。
3. **弹窗/顶部右上角关闭按钮视觉升级**：重构关闭按钮（微圆角胶囊/圆形卡片、淡雅悬浮态、细腻图标过渡），提升精致感。
4. **快速收藏卡片中的文件夹选择器**：同样摆脱原生简陋 `<select>`，升级为支持即时输入搜索、层级清晰、带树形缩进与面包屑高亮的现代浮层下拉组件（FolderPickerDropdown）。

## 2. 详细技术方案

### 2.1 封装通用现代文件夹选择组件（`FolderSelectDropdown` / `FolderPicker`）
- **功能特性**：
  - **单选带层级展示**：支持“根目录”及带有层级缩进（`depth`）与 `Folder` 图标的清晰列表。
  - **就地实时搜索过滤**：顶部提供紧凑的搜索框，支持输入关键词拼音/中英文字符串过滤文件夹，高亮显示父级面包屑或匹配项。
  - **点击外部自动收起（Click Outside）**与键盘无障碍 Esc 关闭。
  - **统一优雅的 UI 视觉**：卡片浮层、细腻阴影、激活项高亮背景、选中标记。
- **适配两种场景**：
  1. **弹窗模式（Modal Form Field）**：作为表单字段，支持展示当前选中的文件夹名称，点击展开搜索浮层。
  2. **快速收藏紧凑模式（Quick Save Bar）**：右侧紧凑触发器，点击后向下弹出自适应对齐的搜索浮层，操作顺手。

### 2.2 优化模态框右上角关闭按钮
- 从老旧的 `background: var(--soft-line); width: 26px; height: 26px;` 升级为：
  - `width: 28px; height: 28px; border-radius: var(--radius-full);`
  - 悬停旋转/缩放微动效、更精致的灰阶过渡、背景高光。

### 2.3 国际化与响应式兼顾
- 搜索框占位符“搜索文件夹…”、“未找到匹配文件夹”等支持中英文动态翻译。

## 3. 实施步骤
1. 在 `apps/sidebar-extension/src/` 创建/提取通用树状可搜索文件夹选择器组件。
2. 将 `App.tsx` 中的快速收藏卡片与 `EditorModal`、`MoveModal` 中的 `<select>` 替换为新组件。
3. 在 `styles.css` 中编写高质感的浮层、搜索框、项高亮及右上角关闭按钮样式。
4. 运行全量单元测试与扩展打包验证。
5. 更新 `VERSION_RECORD.md` 并提交本地 Git。
