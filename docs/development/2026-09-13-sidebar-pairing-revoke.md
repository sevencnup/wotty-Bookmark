# 侧边栏连接码撤销授权

## 目标

在“侧边栏连接”页面展示当前账号创建过的连接码，并允许逐条撤销授权。撤销后，连接码不能再次兑换；已经兑换的侧边栏设备会一并撤销其设备会话。

## 实施步骤

1. 为侧边栏连接码增加撤销时间和已绑定设备字段。
2. 增加已创建连接码列表接口和逐条撤销接口。
3. 生成连接码后保存浏览器名称，兑换时记录对应设备，撤销时联动撤销设备会话。
4. 在管理后台侧边栏连接页面增加连接码列表、状态和“撤销授权”按钮。
5. 补充 API 契约测试、前端构建和后端测试，并创建本地提交。

## 验收标准

- 页面能看到当前账号创建过的每个连接码及浏览器名称。
- 未使用、已连接、已过期和已撤销状态清晰可见。
- 点击“撤销授权”后，该连接码无法继续连接；已连接设备的会话同时失效。
- 其他账号无法读取或撤销当前账号之外的连接码。
