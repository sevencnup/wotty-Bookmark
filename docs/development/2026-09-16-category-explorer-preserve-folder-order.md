# 分类管理保留文件夹原始顺序

## 问题

分类管理的资源管理器视图在接收到服务器书签库树后，前端会递归按文件夹标题进行 A-Z 排序。这覆盖了服务端根据 `position` 返回的原始顺序，导致用户创建、移动后形成的文件夹排列无法按原样显示。

## 目标与验收

1. 根目录和任意子目录均按服务端返回的原始数组顺序展示。
2. 面包屑、文件夹选择下拉选项及书签分组沿用同一棵未重排的文件夹树。
3. 移除界面上的 A-Z / 26 字母排序标识。
4. 添加回归测试，覆盖根目录和子目录顺序不会被标题重排。
5. 通过管理后台完整测试、类型检查和生产构建。

## 实施步骤

1. 将资源管理器当前层目录读取逻辑提取为可测试函数，并直接返回服务端树中的数组顺序。
2. 分类管理全链路改为使用未经前端排序的文件夹树。
3. 删除排序状态标识和无用图标引用。
4. 运行回归测试、完整验证，更新版本记录并创建本地 Git 提交。
