# 修复侧边栏扩展图标显示

## 问题

浏览器扩展详情页显示灰色字母占位，无法显示品牌图标。构建产物包含图标文件，但清单的 `icons` 与 `action.default_icon` 指向了 `logo.webp`。当前浏览器扩展清单对 WebP 图标兼容性不足。

## 方案

将扩展清单图标字段恢复指向已有的 `logo.png`；页面内品牌 Logo 继续使用 `logo.webp`。这样不改变页面视觉资产，同时保证扩展清单在 Chromium 和 Firefox 中可加载。

## 验收

1. 清单图标字段全部指向 `logo.png`。
2. Chrome MV3 生产构建成功，产物包含 `logo.png`。
3. 自动化测试检查清单配置，避免后续再次切换到不兼容格式。
