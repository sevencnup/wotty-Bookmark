# 管理后台语言偏好

## 目标

在“偏好设置”中提供简体中文和 English 两种界面语言。选择后立即更新管理后台的导航、工作区标题、账户入口、登录页和偏好设置本身，并在刷新或重新登录后保持选择。

## 实施步骤

1. 扩展本地偏好数据结构，安全读取、校验并持久化语言值。
2. 建立集中式界面语言字典和翻译函数，避免将中英文文案分散在页面逻辑中。
3. 将管理后台外壳、导航、登录页和偏好设置接入语言选择。
4. 在语言变更时更新 HTML `lang` 属性，保留现有密度和动效设置行为。
5. 增加偏好持久化回归测试，运行前端检查、测试、生产构建并创建本地提交。

## 验收标准

- 偏好设置能选择“简体中文”或“English”，并立即更新管理后台核心界面。
- 刷新页面、退出并重新登录后仍使用上次选择的语言。
- 历史偏好数据和非法语言值安全回退为简体中文。
- 不发送或保存任何服务端账户、书签或密码数据。
