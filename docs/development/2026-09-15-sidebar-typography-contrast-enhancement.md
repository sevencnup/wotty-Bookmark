# 侧边栏全局字体清晰度与低对比度细字优化方案

## 1. 现状痛点
1. **全局滥用等宽字体（ui-monospace）**：
   - 顶部品牌副标（WOTTY · SERVER LIBRARY）、分类眉标（PRIVATE LIBRARY）、快速收藏眉标（收藏当前页 · SERVER）、书签/文件夹数量统计（1012 个书签 · 275 个文件夹）、同步时间、底部页脚等，全部定义了 `ui-monospace, SFMono-Regular, Menlo, monospace`。在 Windows 下会渲染为极细、锯齿严重、字距稀疏的残破点阵字。
2. **文本颜色过浅（--soft-muted: #94a3b8 / 极淡灰）**：
   - 多处副标、提示、元信息采用了 `#94a3b8` 甚至更淡的颜色，并在 10px 极小字号下造成严重的视力疲劳与低辨识度。
3. **字号过小（10px）**：
   - 10px 字体在非高分屏或普通 Windows 缩放下极易糊成一条，需适度提升到 `11px~12px` 并采用正常/加粗无衬线字体。

## 2. 优化改造方案
1. **全面替换等宽字体为系统高品质无衬线字体（Sans-Serif）**：
   - 品牌副标、各模块眉标 kicker/eyebrow、统计信息、同步时间、页脚全面使用统一的现代无衬线字体族。
2. **提升文字颜色对比度**：
   - 将浅灰 `#94a3b8`（`--soft-muted`）统一升级为清晰柔和的石板深灰 `#64748b`（`--muted`）或 `#475569`（`--muted-strong`）。
3. **优化字阶与行高**：
   - 极小 10px 文本提升至 11px~12px，字重微调为 500/600，保证文字饱满易读。
4. **验证与回归**：
   - 测试通过、打包通过，更新版本记录并本地提交。
