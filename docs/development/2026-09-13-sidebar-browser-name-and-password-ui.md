# 侧边栏连接码浏览器名称与密码界面收敛

## 目标

移除管理后台中当前不再使用的“应用密码”管理界面，仅保留侧边栏连接码入口；生成连接码时允许填写浏览器名称，并将名称保存到连接码记录，供后续设备识别使用。Floccus 相关路由和后端兼容接口继续保留，但不在主导航展示。

## 实施步骤

1. 将管理后台密码管理页面收敛为侧边栏连接设置，删除应用密码列表、创建和撤销操作。
2. 在侧边栏连接码生成表单中增加浏览器名称字段，并把名称提交到后端。
3. 扩展连接码数据表和 API，在生成及兑换连接码时保存并使用浏览器名称。
4. 保留应用密码后端接口与 Floccus 隐藏路由，避免破坏已有兼容能力。
5. 运行前端类型检查、构建、后端测试和差异检查，并创建本地提交。

## 验收标准

- “密码管理”页面不再展示应用密码创建、列表和撤销功能。
- 用户可填写浏览器名称后生成侧边栏连接码。
- 连接码记录保存浏览器名称，兑换后设备记录可识别该名称。
- Floccus 页面仍可通过兼容路由访问，但不出现在主侧边栏。
