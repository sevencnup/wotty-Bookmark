# 组织架构树平滑圆润贝塞尔曲线/弧线分支连接方案

## 1. 需求目标与技术原理

### 1.1 用户需求
- 用户希望组织架构树的连线为**圆润弯曲的平滑曲线**（类似于 XMind、MindNode、Figma 等现代思维导图/架构图的平滑弧线分支），而不是生硬的直角硬折线。

### 1.2 性能保证与零卡顿原则（Zero-Cost Smooth Curves）
- **禁止全局遍历重排（No Layout Thrashing）**：不使用旧版基于 `getBoundingClientRect` 频繁读取全量 DOM 坐标的方式。
- **纯 CSS 现代圆角贝塞尔曲线 / 自适应分支弧线体系**：
  - 使用 CSS 几何弧线体系（`border-radius` 连续平滑导轨与圆润分支拐角）或本地确定性几何曲线。
  - 父节点向右引出圆滑发射线；
  - 垂直导轨到每个子文件夹卡片采用平滑的圆弧转折（`border-bottom-left-radius` / `border-top-left-radius` 平滑曲线弧度，例如 16px~20px 平滑贝塞尔圆角），形成自然流动、优雅舒展的树状弧线；
  - 无论展开多少层级、如何拖拽缩放，渲染耗时恒为 **0 ms**，完全保持 120 FPS 满帧。

## 2. 实施方案

1. **圆润分叉弧线设计**：
   - 为每个分支节点的入线与转折处配置高质感平滑弧线（`border-bottom-left-radius: 16px`），使主干垂直线与水平支线自然平滑过渡，消融生硬直角。
   - 根节点与父节点发出的主干线加入微弧度引导。
   - 线条配色升级为具有现代科技感的柔和石板蓝（`#94a3b8` / hover 时高亮 `#3b82f6`），并带有平滑发光微阴影。
2. **验证与交付**：
   - 运行全量单元测试与生产环境打包构建。
   - 更新版本记录并执行本地提交。
