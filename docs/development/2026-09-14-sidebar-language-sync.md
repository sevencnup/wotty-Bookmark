# 侧边栏语言偏好同步

## 目标

让管理后台的界面语言成为账号级偏好。用户在偏好设置中切换简体中文或 English 后，所有已连接的侧边栏插件在下次打开、重新获得焦点或定时刷新时自动采用同一语言。

## 范围与约束

- 偏好由 API 服务端保存，管理后台与侧边栏均通过已认证会话读取。
- 管理后台是语言的唯一写入端；插件只读取并缓存，接口不可用时继续使用缓存语言。
- 不翻译书签、文件夹、网址、账号名称及其他用户数据。
- 保持存量账号兼容：没有偏好记录时默认简体中文。

## 实施步骤

1. 新增账号偏好数据迁移，以及受会话认证保护的读取、更新 API。
2. 管理后台在登录会话可用时读取远端语言，并在语言变更时异步同步。
3. 侧边栏新增独立的中英文界面文案与本地缓存，在连接、打开、重新聚焦、页面重新可见及定时刷新时拉取账号偏好。
4. 覆盖 API、管理后台和插件的关键路径测试，并执行类型检查与生产构建。
5. 更新版本记录并创建本地 Git 提交，不推送远端。

## 验收标准

- `GET /api/v1/preferences` 对已认证用户返回当前语言，存量用户返回 `zh-CN`。
- `PUT /api/v1/preferences` 仅接受 `zh-CN` 与 `en`，且账号之间互不影响。
- 后台切换语言后不依赖刷新即可更新界面，并可被同账号的侧边栏读取。
- 插件在远端暂时不可访问时仍能正常工作且保留最近一次语言。
