# 分类管理组织架构：现代无连线层级岛屿卡片布局方案

## 1. 设计目标与背景

### 1.1 痛点反思
- 传统线条（无论是纯 CSS 直角线还是 SVG 贝塞尔曲线）在遇到多层级、数十个顶级文件夹的复杂书签树时，容易出现连线密集重叠（蜘蛛网效应）、长距离拉扯与视觉干扰。
- 采用 JS 动态测量坐标会导致 DOM 重排与渲染卡顿；采用 CSS 伪元素则在多节点展开时存在几何比例失衡。

### 1.2 现代设计理念（Lineless Hierarchy Panels）
- **完全去线条化**：移除所有连接线、竖线和分支导轨，页面更通透清爽。
- **层级分组岛屿（Hierarchy Group Islands）**：展开的子文件夹用柔和浅底色、圆角虚线/细实线边框包裹，形成清晰的“子集岛屿”，一眼看清父子隶属关系。
- **层级色标与阶梯式微立体卡片**：
  - 顶级根节点：品牌科技感卡片，突出全局统揽地位。
  - 各级文件夹卡片：采用高透白底卡片、悬浮微阴影与左侧层级色标条。
  - 交互体验：拖拽悬停时整个岛屿与目标卡片呈现蓝色外发光与明确引导标签。
- **极致性能**：100% 纯 CSS 布局，滚动、缩放与拖拽始终保持 120 FPS 满帧。
