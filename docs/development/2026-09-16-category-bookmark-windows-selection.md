# 分类管理书签 Windows 式多选

## 需求

分类管理左侧书签列表需要采用 Windows 文件资源管理器的选择习惯：

1. 普通点击书签行时，仅选择当前书签。
2. `Ctrl` 点击时切换当前书签的选择状态；点击已选书签可取消选择。
3. `Shift` 点击时，以最近的选择锚点为起点选择连续范围。
4. `Ctrl + Shift` 点击时保留已有选择，并追加锚点到当前书签之间的连续范围。
5. 已选书签拖入右侧文件夹时，全部已选项目一并归档。

## 约束

- 复选框、外链、文件夹展开按钮与拖拽手柄的既有交互不可被行选择劫持。
- 选区范围必须遵循当前左侧实际展示的书签顺序（含搜索、文件夹筛选和分组顺序）。
- 数据刷新后，已不存在的书签与失效锚点必须安全清理。
- macOS 上将 `Meta` 键视为 `Ctrl` 的等价选择修饰键。

## 验收

1. 连续区间、追加区间、Ctrl 单项添加与取消选择均有纯函数回归测试。
2. 行内按下事件根据修饰键更新选区，且拖拽开始读取同步更新后的选区。
3. 通过管理后台完整测试、类型检查和生产构建。

## 实施步骤

1. 在书签树工具层实现可测试的 Windows 式选区计算函数。
2. 用当前显示顺序和选择锚点接入分类管理书签行。
3. 移除与新模型冲突的按住滑动涂抹选择状态，保持行拖拽和控件交互。
4. 添加回归测试并运行完整验证。
5. 更新版本记录，创建本地 Git 提交。
