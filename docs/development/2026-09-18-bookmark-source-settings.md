# 书签来源设置开发文档

## 需求

将现有“侧边栏连接”页面调整为“书签来源设置”，在保留侧边栏连接码管理的同时，提供两种书签数据源模式：

- 浏览器原生书签：侧边栏读写当前浏览器的原生书签，手机继续使用浏览器自己的同步能力。
- 独立服务器书签：侧边栏读写服务器书签库，不依赖浏览器原生书签。

## 实施步骤

1. 扩展账户偏好接口和数据库字段，保存 `sourceMode`，默认使用 `server` 以兼容当前用户。
2. 将管理后台导航文案和页面标题改为“书签来源设置”。
3. 在原侧边栏连接页面顶部增加来源模式选择卡片，保存到账户偏好；下方保留连接码生成与历史。
4. 让侧边栏启动和重新获得焦点时读取来源模式。
5. 在侧边栏增加浏览器原生书签数据层，支持读取、搜索、展开、当前页收藏、新建、编辑、移动和删除；服务器模式沿用现有数据层。
6. 浏览器模式启用必要的 `bookmarks` 权限，并补充接口、偏好和数据层回归测试。
7. 执行 API 测试、管理后台测试/类型检查、侧边栏测试/类型检查和 Chrome 构建。
8. 更新版本记录并完成本地 Git 提交，不推送 GitHub。

## 兼容与安全约束

- 现有账户默认仍为服务器书签模式，不改变已连接用户的行为。
- 切换来源只改变侧边栏当前读写目标，不自动删除另一侧数据。
- 服务器模式仍需已有侧边栏连接；浏览器模式不要求服务器连接。
- 浏览器书签数据只通过浏览器原生书签 API 访问，不上传服务器。
