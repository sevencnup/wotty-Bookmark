# 侧边栏连接码入口调整

## 目标

将 WOTTY BOOKMARK 侧边栏的一次性连接码从 Floccus 配置向导移动到“密码管理”页面，并把 Floccus 配置保留为隐藏兼容页面。

## 实施步骤

1. 在密码管理页增加侧边栏连接码生成模块，保留 API 地址和设备码复制功能。
2. 从 Floccus 配置向导移除侧边栏连接码模块，避免与密码管理页重复。
3. 将 Floccus 导航项标记为隐藏但保留路由和组件，内部兼容入口仍可使用。
4. 执行前端测试、类型检查和生产构建。

## 验收标准

- 用户可在“密码管理”页面生成侧边栏连接码。
- 连接码仍显示 API 地址、设备码、10 分钟有效期和一次性使用提示。
- Floccus 不再出现在主侧边栏，但相关页面代码和路由未删除。
