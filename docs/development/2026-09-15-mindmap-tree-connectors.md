# 组织架构树优雅思维导图式连线重构方案

## 1. 核心诉求与问题剖析
- 用户对“完全无线条的岛屿卡片”不喜欢，本质上还是想要直观的**树状/思维导图连线**。
- 之前卡顿的原因：
  1. 使用 JS 循环调用 `getBoundingClientRect()` 造成 DOM 重排风暴（Layout Thrashing）。
  2. 根节点直接拉出一两百条线条扎堆（蜘蛛网效应）。
- 真正的解决方式：
  1. **纯 CSS 伪元素绘制思维导图连线**（100% 零 JS 计算，天然 120 FPS 丝滑）。
  2. **局部层级导轨**：每级父节点只管理自己的子列表导轨，根节点引出水平主线，子节点由左侧平滑圆弧分支自然承接。
  3. 卡片保持精致紧凑的思维导图节点形态。

## 2. 实施方案
1. 更新 `apps/admin-web/src/styles.css`：
   - 采用专业思维导图（Mindmap）树状连线体系。
   - 树干线条使用精细的 `#cbd5e1`，转折处 `border-radius: 12px` 自然平滑过渡。
   - 修复每个卡片的几何对齐，确保线条精准对齐图标垂直中心。
2. 运行测试与构建。
3. 更新版本记录并执行本地提交。
