# 服务器书签库 Logo 回退修复

## 背景

服务器书签库列表已经支持服务端批量缓存 favicon，但当 API 尚未更新、站点拒绝服务端抓取或返回非标准图片 MIME 时，前端会直接回退为域名首字母，导致列表看不到网站 Logo。

## 实施步骤

1. 为服务端 favicon 解析增加基于文件头的图片类型识别，兼容缺失或错误的 Content-Type。
2. 为管理后台增加浏览器端同源 favicon 候选回退，并缓存成功的候选地址；服务端结果失效时自动继续尝试。
3. 保留首字母作为最终兜底，不改变书签数据和删除行为。
4. 补充前端与 Rust 回归测试，执行类型检查、测试和生产构建。
5. 更新版本记录并创建本地 Git 提交。

## 验收标准

- 服务端返回空结果时，列表仍会尝试站点常见 favicon 路径。
- 服务端返回非标准 MIME 但内容是 PNG、ICO、SVG 等图片时，图标可以被缓存和展示。
- 图标加载失败不会造成布局抖动，最终仍显示固定尺寸的首字母占位。
- admin-web 类型检查、测试、构建和 API 测试通过。
