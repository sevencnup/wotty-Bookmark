# 管理后台刷新后恢复当前页面

## 背景

管理后台当前页面只保存在 React 内存状态中，浏览器刷新后会重新读取偏好设置里的默认页面，导致用户从“我的书签库”或其他页面刷新后回到“概览”。

## 实施步骤

1. 增加独立的当前页面本地存储键，记录最近一次有效的侧边栏页面。
2. 应用启动时优先恢复最近页面；若页面 ID 已无效，则回退到偏好设置的默认页面或概览。
3. 每次侧边栏导航时同步保存当前页面，不改变默认页面偏好设置。
4. 补充存储读写回归测试，执行类型检查、测试和生产构建。
5. 更新版本记录并创建本地 Git 提交。

## 验收标准

- 刷新管理后台后仍停留在刷新前选中的页面。
- 已删除或无效的页面不会被恢复，能安全回退到概览。
- 修改“默认打开页面”只影响没有历史页面记录的情况。
