# 管理后台书签列表文件夹分组

## 目标

修复分类管理页面左侧书签列表仅平铺展示、无法直观看出文件夹分类的问题。

## 交互方案

- 左侧列表按书签当前所在文件夹分组，根目录作为独立分组。
- 每个分组显示文件夹名称、完整路径、书签数量和选择状态。
- 分组支持展开、折叠和整组勾选，顶部提供全部展开与全部收起。
- 搜索、右侧文件夹筛选、单项勾选、批量移动和拖拽归类能力保持不变。
- 右侧选中父文件夹时，左侧继续显示该文件夹及其子文件夹中的书签，并按实际所在文件夹分类。

## 执行步骤

1. 在书签树工具中增加稳定的文件夹分组函数，并补充根目录、嵌套目录和未知目录测试。
2. 将分类管理左侧列表改为文件夹分组结构，增加分组折叠和整组选择状态。
3. 调整桌面端与窄屏样式，保持列表内部滚动、拖拽和现有后台视觉体系。
4. 执行管理后台类型检查、测试和生产构建。
5. 更新开发记录和版本记录，并完成本地 Git 提交。

## 验收标准

- “全部书签”状态下，书签按实际文件夹分段展示，不再是无层级平铺列表。
- 根目录、一级文件夹和嵌套文件夹均有明确的分组标题与数量。
- 分组折叠、整组选择、全选、搜索和右侧文件夹筛选正确协同。
- 原有书签拖拽归类与打开链接能力不受影响。
- 管理后台类型检查、测试和生产构建通过。

## 执行结果

- 新增稳定的书签文件夹分组工具，根目录置顶，其余目录按组织树顺序展示。
- 左侧书签列表已按实际文件夹分组，支持嵌套路径、折叠、全部展开/收起和整组选择。
- 搜索时自动展开命中的分组；右侧文件夹筛选、单项选择、批量移动、拖拽和打开链接保持可用。
- 右侧总目录卡片已支持点击返回全部书签。
- 管理后台类型检查、15 项测试和生产构建均通过。
- Chromium 使用多层文件夹模拟数据完成验收：5 个分组和 7 条书签全部展示，折叠后行数与无障碍状态正确，左侧列表无横向溢出。
- 临时浏览器会话、截图与开发服务均已清理。
