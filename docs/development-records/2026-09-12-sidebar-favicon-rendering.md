# 侧边栏网站图标渲染修复开发记录

## 问题

部分域名在侧边栏显示默认书签图标，但网站实际返回了可用的 SVG 或图片 favicon。

## 诊断结论

侧边栏 favicon 加载器已经能发现并缓存 SVG，但 `Favicon` 组件只渲染 `image` 类型，`svg` 类型会被误判为加载失败并回退到默认图标。另外，部分站点使用非标准 `Content-Type` 返回 PNG/ICO，原逻辑也会直接忽略。

## 执行步骤

1. 使用现有 SVG 清理结果以内联 SVG 方式渲染，继续保持 16×16 图标槽位。
2. 对带有常见图片扩展名的候选放宽 MIME 判断，兼容 `application/octet-stream` 等非标准响应。
3. 保留原有 Cache Storage 和内存缓存，不重复下载已缓存图标。
4. 增加静态回归断言，确保 SVG 渲染分支不会再次被删除。
5. 执行侧边栏测试、类型检查和生产构建。
