# 自有书签库模式开发记录

## 目标

将 WOTTY BOOKMARK 从仅依赖 Floccus/浏览器原生书签的辅助管理方式，扩展为可由服务器作为唯一数据源的自有书签库模式。用户可以在 WOTTY 浏览器扩展中收藏当前页面，书签直接保存到服务器数据库，不写入浏览器原生书签，也不依赖 Floccus。

## 产品边界

1. 浏览器地址栏原生星标无法被扩展替换；该按钮仍保存到浏览器原生书签。
2. WOTTY 扩展的“收藏当前页”是自有书签库的正式入口，直接调用服务端 API。
3. 自有书签库与 Floccus XBEL 同步库分离，避免两套同步规则覆盖彼此的数据。
4. 本次优先实现自有库的读取、收藏当前页、创建文件夹、移动、删除、恢复及从现有同步文件导入；不监听或删除浏览器原生书签。
5. 浏览器断网时显示可重试错误，不在本次引入不可见的本地持久化队列。

## 执行步骤

1. 新增服务器书签库数据表和用户隔离 API。
2. 扩展现有配对会话权限，使浏览器扩展可访问自有书签库。
3. 改造浏览器侧边栏：列表、搜索、收藏当前页、创建文件夹、移动、删除都直连服务器。
4. 在管理后台分类管理中加入“自有书签库”工作区并提供从当前 Floccus 同步文件导入的迁移入口。
5. 增加测试、执行构建验证、更新版本记录并创建本地提交。

## 完成情况

1. 新增 `library_nodes` 数据表，以及严格按用户隔离的服务器书签库 CRUD、移动、回收站恢复、XBEL 导入和从 Floccus 索引复制接口。
2. 侧边栏改为默认读取和写入 `/api/v1/library`，并从扩展清单移除 `bookmarks` 权限；浏览器地址栏星标仍不受扩展控制。
3. 管理后台新增“我的书签库”入口，可直接管理自有库、迁移旧同步索引或导入 XBEL。
4. 已验证 Rust 全量测试 40 项、管理后台测试 25 项、侧边栏测试 10 项、两个前端类型检查，以及管理后台和 Chrome/Firefox 扩展生产构建。
