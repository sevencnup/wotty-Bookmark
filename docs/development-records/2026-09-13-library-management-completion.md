# 服务器书签库管理功能补全开发记录

## 目标

补齐全局功能审计中确认的三类缺口：管理后台服务器书签库的编辑与移动、服务器书签库回收站的永久删除与清空、危险操作确认偏好的实际生效。

## 执行步骤

1. 为服务器书签库回收站增加条目永久删除和清空 API，并保持用户隔离。
2. 在管理后台服务器书签库列表增加编辑、移动、文件夹操作和回收站操作。
3. 统一读取危险操作确认偏好，关闭确认时直接执行，开启时显示确认弹窗。
4. 更新前端、后端和根目录版本记录。
5. 执行 Rust API 测试、管理后台测试、类型检查和生产构建。

## 接口与页面变更

- `DELETE /api/v1/library/trash/:id` 仅允许当前用户永久删除一个回收站根节点及其软删除子树。
- `POST /api/v1/library/trash/empty` 清空当前用户全部服务器书签库回收站内容。
- “我的服务器书签库”页面提供书签/文件夹编辑、移动、删除、恢复、永久删除和清空操作。
- 文件夹移动目标会排除自身及自身后代，避免形成循环层级。

## 验收标准

- 管理后台可以编辑服务器书签标题/网址、重命名文件夹、移动节点。
- 服务器书签库回收站支持恢复、永久删除和清空。
- 危险操作确认开关会影响服务器书签删除、回收站清理、设备撤销和备份还原等操作。
- 所有现有测试与构建通过。
