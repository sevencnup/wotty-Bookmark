# 服务器书签库 Logo 稳定加载

## 背景

服务器书签库 Logo 在候选地址失败或网络较慢时会出现闪烁：页面先渲染一个尚未加载完成的图片，再快速切换到下一个候选地址。部分站点首页请求失败时，服务端也会提前终止 favicon 解析。

## 实施步骤

1. 管理后台使用隐藏的 `Image` 预加载候选地址，只有图片加载成功后才替换当前显示的 Logo。
2. 单个候选设置超时，失败或超时后继续尝试下一个地址；加载期间保持首字母或旧 Logo。
3. 服务端首页不可访问时仍继续尝试 `/favicon.ico`、`/favicon.svg` 等标准路径。
4. 更新版本记录，执行 admin-web 类型检查、测试、构建和 Rust favicon 测试。
5. 创建本地 Git 提交，不推送远程仓库。

## 验收标准

- 候选切换过程中不显示破损图片或空白闪烁。
- 已显示的 Logo 在新候选加载成功前保持稳定。
- 首页返回错误不会阻断标准 favicon 路径探测。
- 所有相关测试和构建通过。
