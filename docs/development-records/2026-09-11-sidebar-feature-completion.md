# 侧边栏未实现功能补全开发记录

## 目标

盘点管理后台侧边栏页面，识别仅有占位、不可操作或功能链路不完整的页面，并在现有数据模型与同步边界内补齐可安全实现的功能。

## 执行步骤

1. 盘点侧边栏入口、路由分支、页面组件及其 API 调用。
2. 对照后端接口、数据库迁移和现有测试，确认每个页面是否具备真实读写能力。
3. 优先补齐数据备份页面的下载、校验与还原闭环；还原前自动保护当前数据，并保证失败可恢复。
4. 对当前同步协议不支持的数据能力不伪造实现；必要时移除对应占位入口并记录原因。
5. 为新增行为补充前后端测试，执行格式化、测试、lint 和构建。
6. 更新版本记录并提交本地 Git 变更，不推送远端。

## 范围判断

- 标签管理目前没有稳定的跨设备数据模型，先按架构边界处理，不使用演示数据冒充真实能力。
- 安全页删除账户按钮不属于当前可见侧边栏入口，除非盘点发现其被实际导航使用，否则不扩大本次范围。
