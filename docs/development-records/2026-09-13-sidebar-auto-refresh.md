# 侧边栏书签库自动同步开发记录

## 目标

让侧边栏在管理后台、其他浏览器标签页或其他设备修改服务器书签后，能够自动看到最新数据。

## 执行步骤

1. 为侧边栏书签库加载增加静默刷新模式，静默刷新时保留当前列表，避免刷新闪烁。
2. 使用单请求锁，避免定时器、窗口焦点和可见性事件同时触发重复请求。
3. 页面可见期间每 10 秒刷新一次；侧边栏重新获得焦点或恢复可见时立即刷新。
4. 在书签库统计区域显示最近同步时间，并保留手动刷新按钮。
5. 清理定时器和事件监听器，更新侧边栏版本记录及开发记录。
6. 执行侧边栏单元测试、类型检查、生产构建和 Git 差异检查。

## 验收标准

- 侧边栏新增书签后，已打开的管理后台或侧边栏最多约 10 秒内看到更新。
- 自动刷新期间当前列表不被 Loading 状态替换。
- 窗口重新聚焦或页面恢复可见时会立即请求一次最新书签。
- 组件卸载后不再残留定时器或事件监听器。
