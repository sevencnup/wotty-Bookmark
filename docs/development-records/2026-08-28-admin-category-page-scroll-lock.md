# 分类管理页面滚动边界修复

## 目标

修复桌面端分类管理页面可以整体滚动、应用壳被移出视口并露出大块空白的问题。

## 执行步骤

1. 固定桌面端根节点和应用壳的视口高度，禁止页面级滚动。
2. 保留主内容区、侧边导航和分类管理内部面板的独立滚动。
3. 在窄屏布局恢复自然页面滚动，避免移动端内容被裁切。
4. 执行类型检查、测试和生产构建，确认样式调整未引入回归。
5. 更新开发记录和版本记录并提交本地仓库。

## 验收标准

- 桌面端分类管理页面无法将整个应用壳上下滑出视口。
- 左侧书签列表和右侧组织树仍可独立滚动。
- 窄屏布局仍能完整浏览两个模块。
- 管理后台类型检查、测试和构建通过。

## 执行结果

- 首轮使用根节点百分比高度和 `overflow: hidden`，类型检查、13 项测试和生产构建均通过。
- 用户复验确认首轮方案仍可将整个应用壳滑出视口，因此不能视为验收通过。

## 修订方案

1. 桌面端将应用壳固定到视口四边，彻底脱离页面级滚动范围。
2. 窄屏断点恢复静态定位和自然页面滚动。
3. 使用真实浏览器执行滚轮操作，对比滚动前后应用壳、左侧书签面板和右侧组织树面板的坐标。

## 最终结果

- 桌面端应用壳已固定到视口四边，分类页主内容区已禁止滚动穿透。
- 在左侧列表滚动到底后继续滚轮，根文档和主内容区滚动位置均保持为 `0`。
- 滚动前后应用壳、左侧书签面板和右侧组织树面板坐标完全一致。
- 640px 窄屏下应用壳恢复静态定位，页面保持自然滚动。
- 临时 Playwright 用例已删除。
- 类型检查、13 项测试和生产构建均通过。
