# 服务器书签库 Logo 缓存目录初始化

## 背景

本地开发的数据目录中只有数据库和同步文件时，用户无法判断 favicon 缓存是否启用。原实现仅在成功抓取第一张 Logo 后才创建 `favicon-cache` 目录；如果站点无法访问，目录会一直不存在。

## 实施步骤

1. API 启动时主动创建 `DATA_DIR/favicon-cache`。
2. 保持单个图标文件按需写入，不改变缓存格式和 SSRF 防护。
3. 更新开发记录和版本记录，执行 Rust 测试并创建本地提交。

## 验收标准

- API 重启后缓存目录立即存在。
- 远程 Logo 抓取失败不会影响 API 启动。
- 成功解析的图标仍写入同一缓存目录。
