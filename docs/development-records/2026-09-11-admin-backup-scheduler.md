# 管理后台自动备份开发记录

## 任务

为自部署书签服务增加服务器级自动备份能力：支持每日指定时间执行、配置最多保留份数、手动立即备份，并在管理后台展示备份状态与历史记录。

## 范围

1. 使用 SQLite 事务快照备份数据库，并复制服务主密钥、同步文件和历史版本目录。
2. 备份文件保存到数据目录下的 backups 子目录，自动排除备份目录本身。
3. 增加备份设置、手动执行和历史记录 API；只允许已登录管理会话访问。
4. 增加后台定时调度器，按服务端本地时间每日执行，并按保留份数清理旧备份。
5. 增加“数据备份”管理页，提供启用开关、每日时间、保留份数、立即备份和运行状态。
6. 不在本次变更中实现跨机器上传、云端对象存储或在线恢复覆盖，避免误操作破坏当前数据。

## 执行步骤

1. 增加备份设置与运行记录数据库迁移。
2. 实现 Rust 备份服务、调度器、API 路由和保留策略。
3. 实现管理后台 API 类型、备份设置页和导航入口。
4. 增加后端与前端回归测试，运行 lint、test、build。
5. 更新开发记录与版本记录并完成本地 Git 提交。
