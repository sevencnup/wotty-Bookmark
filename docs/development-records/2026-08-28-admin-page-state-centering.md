# 管理后台整页提示状态居中

## 目标

统一管理后台整页级空状态、加载状态和能力提示的布局，使其在桌面端右侧内容区垂直居中，与分类管理页面保持一致。

## 调整范围

- 书签整理页的加载、加密、格式异常和未同步状态。
- 回收站页的加载、不可用和空状态。
- 标签管理页的能力提示。
- 备份、操作日志等待开发页面的整页提示。

## 保持不变

- 应用密码、设备列表、历史版本、帮助搜索和存储摘要中的面板内部空状态。
- 有真实内容时的正常页面布局。
- 移动端自然文档流和滚动行为。

## 执行步骤

1. 为整页提示页面增加明确的布局状态 class。
2. 使用统一的纵向 Flex 规则将提示内容作为一个整体居中。
3. 在移动端断点解除固定高度，避免内容被裁切。
4. 使用 Playwright 验证代表性整页提示和局部空状态的坐标。
5. 执行类型检查、测试和生产构建。
6. 更新开发记录与版本记录并提交本地仓库。

## 验收标准

- 整页提示内容在右侧可用区域水平、垂直居中。
- 提示图标、标题、说明和按钮保持紧凑，不分散到页面不同高度。
- 局部空状态仍留在所属面板内。
- 移动端内容可完整浏览。

## 执行结果

- 书签整理、回收站、标签管理和待开发页面的整页提示已统一居中。
- 应用密码等局部空状态仍保留在所属面板内。
- 5 项 Playwright 布局检查全部通过。
- 临时 Playwright 用例和结果文件已删除。
- 类型检查、13 项测试和生产构建均通过。
