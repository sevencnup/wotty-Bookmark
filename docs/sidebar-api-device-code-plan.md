# 侧边栏 API 地址与设备码连接方案

## 目标

将侧边栏原有的单一连接码输入调整为 API 地址和一次性设备码两个字段，同时保留旧版 `bvpair.v1.*` 连接码的兼容能力。

## 实施步骤

1. 后端配对接口返回独立的 API 地址和一次性设备码，兑换接口同时接受新设备码和旧版打包连接码。
2. 管理后台展示并支持分别复制 API 地址与设备码。
3. 侧边栏连接弹窗提供 API 地址、设备码输入，并完成地址规范化、校验及连接状态保存。
4. 补充协议解析和请求行为测试，执行后端、管理后台与侧边栏的检查和构建。
5. 更新开发记录与版本记录，完成本地 Git 提交。

## 验收标准

- 使用管理后台新生成的 API 地址和设备码可以成功兑换侧边栏会话。
- API 地址尾部斜杠不会产生重复路径，非法协议会在请求前被拦截。
- 旧版 `bvpair.v1.*` 连接码仍可通过侧边栏连接。
- 设备码仍为 10 分钟有效且只能使用一次。
