# Bookmark Vault 前端 UI/UX 深度优化开发文档

## 1. 需求与优化目标

提升 Bookmark Vault 两大前端应用（管理后台 `admin-web` 与浏览器侧边栏扩展 `sidebar-extension`）的视觉质感、设计一致性、交互流畅度与响应式体验。

### 核心优化原则
1. **现代化设计语言 (Modern & Clean)**：引入现代 SaaS（如 Linear, Raycast, Vercel）的高级质感，包括微质感阴影、柔和边框、精心调校的色彩层级与平滑过渡。
2. **统一色彩与设计令牌 (Design Tokens)**：统一主色调、辅助色、状态色（成功/警告/危险/信息）、背景底色与中性字色，消除原先杂乱不协调的高饱和度黄绿色。
3. **更丝滑的交互体验 (Micro-interactions)**：增加按钮 Hover/Active 微动画、卡片渐变微光、弹窗优雅展开、表单输入框聚焦光效、骨架屏微光和无缝拖拽状态。
4. **提升信息层级与排版 (Typography & Spacing)**：优化中西文字体混排、字重比例、行高、留白空间和响应式断点排版。

## 2. 优化模块与具体改动方案

### 2.1 管理后台 (`apps/admin-web`)

#### A. 视觉基石与全局样式系统 (`styles.css`)
- **CSS 变量系统**：重构 `--ink`, `--muted`, `--line`, `--canvas`, `--primary`, `--primary-hover`, `--primary-soft`, `--shadow-sm/md/lg`, `--radius-sm/md/lg` 等设计令牌。
- **自定义滚动条**：设计细腻极简的滚动条。
- **排版与抗锯齿**：优化字体渲染、字母间距与层级。

#### B. 导航与布局骨架 (`Sidebar`, `Topbar`, `AppShell`)
- 侧边栏品牌区域增加微渐变高光与更具层次的图标底座。
- 导航项（Nav Items）增加平滑的左侧指示条动效与悬浮微光。
- 顶部导航栏（Topbar）采用更加清爽现代的层级设计，增加面包屑/标题状态。

#### C. 登录/注册界面 (`LoginCard`)
- 采用精致的毛玻璃/卡片浮层，配合柔和环境光渐变背景。
- 输入框与提交按钮微质感升级，切换模式时提供平滑视觉过渡。

#### D. 概览仪表盘 (`Overview`)
- 重构原先突兀的亮黄色 Hero Card，升级为精致的品牌蓝紫微渐变英雄卡片。
- 统计卡片 (StatCard) 增加轻量悬停浮起动画与渐变色图标背景。
- 快速入门步骤条 (Steps) 重构为现代化时间轴/引导卡片。

#### E. 书签整理器 (`BookmarkOrganizer`)
- 顶部概览 Banner 采用柔和的现代卡片风格。
- 左侧文件夹树：优化树形缩进、文件夹图标、活动态高亮与计数徽标。
- 右侧工具栏与批量操作栏：搜索框、批量移动下拉框、刷新按钮视觉现代化。
- 书签表格：优化站点 Favicon 占位色块与文字排版、整行悬浮高亮、外链按钮与选中态样式。

#### F. Floccus 配置向导与账号管理 (`FloccusGuide`, `AccountSettings`)
- 步骤引导卡片卡线与序号徽章重新设计。
- 统一配置项复制卡片（`ConfigField`）交互，增加成功反馈动画。
- 侧边栏连接码与密钥展示框升级为高对比度安全卡片样式。

---

### 2.2 浏览器侧边栏扩展 (`apps/sidebar-extension`)

#### A. 视觉质感升级
- 优化头部品牌 Lockup、后台连接状态指示点（呼吸光效与精致状态芯片）。
- 快速收藏卡片 (Quick Save Card) 提升层次感与轻微渐变边框。

#### B. 书签树与拖拽体验
- 文件夹展开/折叠更平滑。
- 拖拽插入提示线（`drop-before`, `drop-after`, `drop-inside`）更加清晰醒目且平滑。
- 优化书签列表项的 Hover Actions 悬浮按钮组，增加操作友好度。
- 搜索结果卡片与面包屑路径视觉优化。

#### C. 模态框与连接向导
- 弹窗背景模糊毛玻璃效果（`backdrop-filter: blur`）。
- 弹窗卡片边框高光与阴影升级。
